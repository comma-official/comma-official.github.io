# COMMA 공식 홈페이지

**A small break for your everyday flow.**
일상 속 나만의 회복을 찾아가는 맞춤형 일상 회복 서비스, COMMA의 공식 홈페이지입니다.

🔗 https://comma-official.github.io

## COMMA
| 구성 | 설명 |
| --- | --- |
| **DOT** | 사용자의 일상과 상태를 살피고, 필요한 회복 자원을 안내하며 회복의 순간을 기록할 수 있도록 돕는 디바이스 |
| **COMMA App** | 현재 상태와 과거 기록을 바탕으로 회복 활동을 추천하고, 기록과 탐색을 잇는 앱 |
